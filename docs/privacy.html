Política de Privacidade — PS DesKom

Última atualização: Março de 2026

Resumo de Privacidade: O PS DesKom é uma aplicação nativa de desktop desenvolvida pela Gradle Studio. Todo o processamento de arquivos, descompactação, organização e auditoria ocorre localmente no seu computador. Não vendemos nem compartilhamos seus dados pessoais ou de arquivos com terceiros.

1. Informações do Desenvolvedor

Razão Social / Desenvolvedor: Gradle Studio
E-mail de Contato: gradlestudio.dev@gmail.com
Foro Elegido: Fortaleza, Ceará, Brasil.

2. Coleta e Uso de Dados do Usuário

O PS DesKom coleta e utiliza apenas o estritamente necessário para o funcionamento das ferramentas de produtividade do software:

  • Identificador de Hardware (HWID): Um código hash único gerado a partir de componentes locais do seu computador para validação e ativação da licença do software offline.
  • Arquivos do Usuário: Processados 100% no seu dispositivo. Nenhum conteúdo de arquivo, documento, imagem, áudio ou vídeo selecionado para cópia, movimentação ou organização é enviado para servidores externos.

3. Integração Google OAuth2 e Google Drive Scope

Quando você utiliza a funcionalidade de integração com o Google Drive no PS DesKom, solicitará autenticação via Google OAuth2 com o escopo limitado https://www.googleapis.com/auth/drive.file.

  • Escopo Limitado: O PS DesKom acessa e manipula apenas os arquivos selecionados ou criados explicitamente por você através da aplicação.
  • Uso dos Dados: Os tokens de acesso obtidos são armazenados exclusivamente no seu dispositivo local (via SharedPreferences / Windows Credential Store) para autorizar a sincronização e cópia de arquivos.
  • Conformidade com a Política de Dados de Usuário dos Serviços de API do Google: O uso e a transferência para qualquer outro aplicativo das informações recebidas das APIs do Google pelo PS DesKom atenderão à Política de Dados de Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).

4. Módulo de IA Local e Chaves de API (BYOK)

Nas edições Master e Dev, o módulo de IA Local (LM Studio) funciona via REST API no endereço local http://127.0.0.1:1234. Nenhuma instrução digitada sai da sua máquina no modo local. Caso você cadastre chaves de API externas (Google Gemini, Anthropic Claude ou OpenAI), as chaves são salvas criptografadas no seu dispositivo e enviadas diretamente do seu computador para os respectivos provedores.

5. Compartilhamento e Transferência de Dados

A Gradle Studio NÃO compartilha, vende, aluga ou transfere dados de usuários, tokens do Google ou arquivos para terceiros, corretores de dados ou plataformas publicitárias.

6. Segurança dos Dados

Utilizamos práticas de segurança padrão da indústria para proteger as informações mantidas no seu dispositivo local, incluindo codificação UTF-8 segura, isolamento em sandbox do sistema operacional e armazenamento de credenciais protegidas no Windows.

7. Direitos do Usuário e LGPD

Em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018), você possui o direito de revogar o acesso à sua conta do Google a qualquer momento através das Configurações de Segurança da sua Conta Google ou clicando em "Desconectar Conta" dentro do PS DesKom.

8. Contato e Dúvidas

Se você tiver dúvidas sobre esta Política de Privacidade ou sobre o tratamento de dados do PS DesKom, entre em contato através do e-mail: gradlestudio.dev@gmail.com.
