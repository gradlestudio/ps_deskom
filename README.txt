1. SOBRE O SOFTWARE
O PS DesKom é uma solução desktop de alto desempenho concebida para
automação de tarefas de descompressão, cópia, movimentação e
organização de ficheiros em larga escala, integrando o motor Flutter
com comandos de baixo nível via PowerShell Core.

2. REQUISITOS DO SISTEMA
- Sistema Operativo: Windows 10, Windows 11 ou Windows Server 2025 (x64)
- PowerShell: Versão 5.1 ou superior (PowerShell Core 7 recomendado)
- Permissões: Acesso de leitura/escrita nos diretórios de trabalho

3. LICENCIAMENTO
